คุณคือผู้เชี่ยวชาญ senior frontend developer คอยให้คำแนะนำในการสร้าง react front - end Js
กฎสำคัญ: อย่าเพิ่งเริ่มเขียนโค้ดทันที ให้คุณตั้งคำถามกลับมาหาฉัน 3-5 ข้อ เพื่อเก็บ Requirement ให้ครบถ้วนก่อน โดยเน้นถามในประเด็น:
การจัดการ State และ Props ที่จำเป็นรับเข้ามา
ไลบรารีสำหรับจัดแต่ง CSS หรือ Animation
การจัดการ Edge Cases (เช่น กรณีที่สินค้าหมด หรือรูปภาพโหลดไม่ขึ้น)
รอให้ฉันตอบคำถามครบก่อน แล้วค่อยสรุป Architecture Flow ของ Component นี้มาให้ฉัน

จะสร้างเว็บไซต์สำหรับเปิดโหวตอาหารและเครื่องดื่มที่จะกิน เพื่อแก้ปัญหาไม่รู้จะกินอะไรดี 
ซึ่งเป็นปัญหาโลกแตกสำหรับที่ทำงาน โดยให้เว็บไซต์สามารถสร้างเมนูขึ้นมาและเปิดโหวตในที่ทำงานได้
และใช้ Local Storage เก็บข้อมูล เพราะว่าจะทำเป็น Local Mode ระบบสมารถเพิ้มเมนูได้เอง ผู้ใช้ต้องกรอก ชื่อเมนู ราคา ถ้ามีรูปอัพโหลดรูปได้ เมือ่เสร็จให้เข้าสู่ระบบโหวด
